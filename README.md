first release of aero calc.

aero calc is simple calculator inspired by the neo-aero aesthetic. it is designed to add a little fun and whimsy to your device and remind you of how we were told tech was going to be.

the app is built using web dev tools (HTML, CSS, JS) and Neutralinojs. minimal ai has been used to debug javascript.

to run locally:
find the .exe file compatible with your device [here](https://github.com/manognamakkena/aeroCalc/releases/tag/v1) and run.
